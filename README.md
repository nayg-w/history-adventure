# 시간의 기록자 — 사라진 역사

초등학교 5학년을 위한 **한국사 탐험 어드벤처 웹게임**입니다.
찢어지고 뒤섞인 역사 기록을 단서로 복원하면서 사건의 순서와 원인·결과를 자연스럽게 복습합니다.

- 대상: 초등 5학년 · PC/태블릿 웹브라우저 (마우스·터치·키보드)
- 회원가입 없음 · 개인정보 수집 없음 · 외부 서버/유료 API 없음
- 진행 상황은 브라우저 `localStorage`에만 저장됩니다.

## 실행 방법

빌드 과정이 없습니다.

1. **가장 간단한 방법**: `index.html` 파일을 크롬/엣지/사파리에서 엽니다.
2. **로컬 서버로 실행** (Node.js 필요): `npm start` → 브라우저에서 <http://localhost:8080>
3. **GitHub Pages**: 저장소 Settings → Pages → 브랜치의 루트(`/`)를 지정하면 그대로 배포됩니다.

### 🧩 추론판 사용법

1. 위쪽에서 **탐구 질문**을 고릅니다. 지금 장면에서 풀 질문이 먼저 열려 있고, 1018년 질문은 나중에 열립니다.
2. 아래 단서 카드(거란 쪽 이야기 / 고려 쪽 기록 / 지도와 현장)를 눌러 빈칸 ①②에 넣습니다. ⓘ를 누르면 단서를 얻은 곳과 내용을 다시 볼 수 있습니다.
3. **이어 보기**를 누릅니다. 실이 이어지면 근거에 맞는 결론을 고르고, 끊어지면 고른 단서에 맞춘 이유를 읽고 다시 시도합니다. 벌점은 없습니다.
4. 막히면 추론판 안의 💡힌트를 누릅니다. 1단계는 생각 방향, 2단계는 찾아볼 범위, 3단계는 연결 힌트입니다.

처음 열 때만 짧은 사용법 안내가 나오며, 건너뛸 수 있습니다.

## 역사 내용과 허구의 구분

- 단서 카드에 **실제 역사** / **게임 속 설정** 꼬리표가 붙습니다.
- 대화창의 인물 이름 옆에 **실존 인물 · 대사는 창작** / **게임 속 가상 인물** 꼬리표가 붙습니다.
- 필이(시간의 붓), 병사 바우, 근심 많은 관리, 정찰 보고서, 시간의 서고 등은 게임에서 만든 것입니다.
- 지도는 단순화했고 성의 위치는 대략적입니다.
- 내용 검토가 필요하면 `js/data/episodes/goryeo-khitan.js` 한 파일만 보면 됩니다.

```
index.html

js/puzzles/     재사용 가능한 퍼즐 종류 (debate 협상, mapPlace 지도, battlePlan 작전도, campaign 상황 판단, timeline, causeLink, restore)

js/data/eras.js 8개 시대 목록 (교육과정에 맞게 여기서 조정)
js/data/episodes/goryeo-khitan.js  고려 에피소드의 대사·단서·퍼즐 설정
js/main.js      화면 흐름 (처음 화면, 시대 선택, 완료, 연대표, 설정)
tests/playthrough.js  전체 자동 플레이 테스트
```

### 새 에피소드 추가하기

1. `js/data/episodes/새에피소드.js`에서 `HA.episodes['id'] = { version, characters, clues, insights, secrets, items, recipes, scenes, summary, ... }` 를 등록합니다 (고려 파일을 본보기로 사용). 내용을 크게 바꾸면 `version`을 올려 옛 저장이 새 내용으로 안전하게 시작되게 합니다.
2. `js/data/eras.js`의 해당 시대 `episodes` 배열에 id를 넣습니다.
3. `index.html`에 스크립트 한 줄을 추가합니다.

## 테스트

```
npm install          # playwright 설치 (처음 한 번)
npx playwright install chromium
npm test
```

- `tests/playthrough.js`: 고려 에피소드를 처음부터 끝까지 플레이합니다. 틀린 선택, 담판에서 물러났다 다시 오기, 추론판, 작전 실패 후 재시도, 작전 도중 새로고침 후 이어하기를 포함하고, `tests/shots/`에 스크린숏을 남깁니다.
- `tests/edgecases.js`: 옛 저장 처리, 담판 결렬 후 같은 단계에서 재개, 퍼즐 안 단계별 힌트, 메뉴로 나갔다 와도 진행 단계 유지를 확인합니다.
