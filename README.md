# 시간의 기록자 — 사라진 역사

초등학교 5학년을 위한 **한국사 탐험 어드벤처 웹게임**입니다.
찢어지고 뒤섞인 역사 기록을 단서로 복원하면서 사건의 순서와 원인·결과를 자연스럽게 복습합니다.

- 대상: 초등 5학년 · PC/태블릿 웹브라우저 (마우스·터치·키보드)
- 회원가입 없음 · 개인정보 수집 없음 · 외부 서버/유료 API 없음
- 진행 상황은 브라우저 `localStorage`에만 저장됩니다.

## 실행 방법

빌드 과정이 없습니다.

1. **가장 간단한 방법**: `index.html` 파일을 크롬/엣지/사파리에서 엽니다.
2. **로컬 서버로 실행** (Node.js 필요): `npm start` → 브라우저에서 <http://localhost:8080>
3. **GitHub Pages**: 저장소 Settings → Pages → 브랜치의 루트(`/`)를 지정하면 그대로 배포됩니다.

### 고려 에피소드 흐름

1. **993년 고려 조정** — 인물·사물을 눌러 단서 4개 수집 (정찰 보고서, 지도, 깃발, 옛 기록)
2. **퍼즐 ① 서희의 담판** — 소손녕의 주장에 맞는 *단서 카드*를 내밀어 반박
3. **퍼즐 ② 강동 6주 쌓기** — 성 6개를 지도의 알맞은 지역에 끌어다 놓기 (지역별 다른 피드백)
4. **1018년 흥화진 진영** — 단서 수집 + 도구 줍기 → **도구 합치기**(쇠가죽+밧줄=쇠가죽 둑) → 냇물에 사용
5. **퍼즐 ③ 냇물 작전** — 둑 설치 → 기병 숨기기 → 알맞은 때 둑 터뜨리기 (놓쳐도 다음 무리가 옴)
6. **퍼즐 ④ 귀주대첩** — 바람이 부는 순간 깃발로 공격 신호
7. **퍼즐 ⑤ 시간 순서 복원** — 기록 조각 6개 배열 (맞은 조각은 고정, 틀린 조각만 돌아옴)
8. **퍼즐 ⑥ 원인과 결과 잇기** — 원인 5개와 결과 5개를 실로 연결
9. **기록 복원 연출 → 완료 화면** (실제 역사 정리, 생각해 볼 질문, 게임 속 설정 안내) → **연대표 기록**

공통 기능: 💡단계별 힌트(H) · 📖기록 수첩(단서/도구/인물, N) · ☰메뉴(Esc) · 자동 저장/이어하기 · 에피소드 다시 하기 · 전체 초기화

## 역사 내용과 허구의 구분

- 단서 카드에 **실제 역사** / **게임 속 설정** 꼬리표가 붙습니다.
- 대화창의 인물 이름 옆에 **실존 인물 · 대사는 창작** / **게임 속 가상 인물** 꼬리표가 붙습니다.
- 필이(시간의 붓), 병사 바우, 근심 많은 관리, 정찰 보고서, 시간의 서고 등은 게임에서 만든 것입니다.
- 지도는 단순화했고 성의 위치는 대략적입니다.
- 내용 검토가 필요하면 `js/data/episodes/goryeo-khitan.js` 한 파일만 보면 됩니다.

## 폴더 구조

```
index.html
css/style.css
js/core/        엔진 (저장, UI, 장면·핫스팟·단서·도구·힌트 실행)
js/puzzles/     재사용 가능한 퍼즐 종류 (debate, mapPlace, dam, signal, timeline, causeLink, restore)
js/art/         SVG 그림 (공용 인물 + 시대별 배경)
js/data/eras.js 8개 시대 목록 (교육과정에 맞게 여기서 조정)
js/data/episodes/goryeo-khitan.js  고려 에피소드의 대사·단서·퍼즐 설정
js/main.js      화면 흐름 (처음 화면, 시대 선택, 완료, 연대표, 설정)
tests/playthrough.js  전체 자동 플레이 테스트
```

### 새 에피소드 추가하기

1. `js/data/episodes/새에피소드.js`에서 `HA.episodes['id'] = { characters, clues, items, recipes, scenes, summary, ... }` 를 등록합니다 (고려 파일을 본보기로 사용).
2. `js/data/eras.js`의 해당 시대 `episodes` 배열에 id를 넣습니다.
3. `index.html`에 스크립트 한 줄을 추가합니다.

## 테스트

```
npm install          # playwright 설치 (처음 한 번)
npx playwright install chromium
npm test
```

`tests/playthrough.js`가 브라우저에서 고려 에피소드를 처음부터 끝까지 플레이하며(틀린 선택·힌트·드래그·도구 합치기 포함) 완료 저장, 연대표 기록, 새로고침 후 이어하기, 키보드 단축키를 확인하고 `tests/shots/`에 스크린숏을 남깁니다.
